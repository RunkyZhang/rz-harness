# SFA Domain Glossary

> 用途：统一业务术语，减少 AI 在 spec、contract、review 中使用含糊或互相冲突的词。只记录业务语言，不记录实现细节。

## 使用规则

- 新需求进入 spec 前，先检查本文件是否已有相关术语。
- 如果用户使用的词和本文件定义冲突，先澄清，不直接实现。
- 如果代码里的命名和业务说法不一致，同时记录“业务术语”和“代码标识”。
- 术语定义必须有来源：用户确认、PRD、飞书文档、现有代码或契约。
